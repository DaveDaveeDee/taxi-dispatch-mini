# Taxi Dispatch Mini

Ett litet demo-system med två mikrotjänster som visar hur förare matchas mot resor.

## Tjänster
- `driver-service` – hanterar förare och deras status (ledig/upptagen)
- `ride-service` – tar emot resebeställningar och tilldelar en ledig förare

## Tech stack
Java 21, Spring Boot, Maven, Docker, Kubernetes, Jenkins/GitHub Actions
